# PaperNest – Online Stationery Store

- **Name:** Tadas-Okonkwo Nnamdi
- **Matric number:** 23/SCI01/149
- **Project title:** PaperNest – Online Stationery Store

An e-commerce website where students and office workers can buy stationery: notebooks, pens, highlighters, sticky notes, files, staplers, art supplies and planners.

**Features:** homepage with featured products and deals, product catalogue with real photos, search and filters, shopping cart, checkout with delivery details, online payment through Kora (test mode) or pay on delivery, registration and login, a profile menu and profile page, and an admin dashboard (sales chart, transactions, add/edit/delete products, photo upload, receive goods, order management).

## How to run

1. Unzip `PaperNest.zip`.
2. Inside the `papernest` folder run `npm install`, then `npm start`.
3. Open http://localhost:3000. Node.js 22.13 or newer is required.
